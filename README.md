# سرمایه‌یار (SarmayeYar)

دستیار هوشمند سرمایه‌گذاری — کاربر یک دارایی (سهام، ارز دیجیتال، طلا، فارکس) را انتخاب می‌کند
و سیستم داده بازار، روند قیمت، اخبار و ریسک را تحلیل کرده و به‌جای سیگنال قطعی «بخر/بفروش»،
یک **امتیاز** و **سناریوهای احتمالاتی** (صعودی/خنثی/نزولی) ارائه می‌دهد.

## پشته فناوری
- بک‌اند: Python 3.11 + FastAPI + SQLAlchemy
- رندر صفحات: Jinja2 (سمت سرور، برای سئوی کامل — بدون نیاز به SPA)
- داده و تحلیل: pandas / numpy / yfinance / feedparser
- پایگاه‌داده: SQLite به‌صورت پیش‌فرض (با تغییر `DATABASE_URL` قابل تعویض به PostgreSQL)
- استقرار: Docker → Render

## اجرای محلی با Docker
```bash
docker compose up --build
```
سپس به آدرس `http://localhost:8000` بروید. پنل مدیریت در `http://localhost:8000/admin` است.

اطلاعات ورود پیش‌فرض ادمین (در `docker-compose.yml` قابل تغییر است):
- ایمیل: `admin@sarmayeyar.local`
- رمز عبور: `ChangeMe123!`

**پیش از انتشار عمومی، حتماً این رمز را از طریق متغیر محیطی `ADMIN_PASSWORD` تغییر دهید.**

## اجرای محلی بدون Docker
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

## استقرار روی Render
1. مخزن (ریپازیتوری) این پروژه را روی گیت‌هاب قرار دهید.
2. در Render یک **Web Service** جدید بسازید و گزینه **Docker** را انتخاب کنید (یا از فایل `render.yaml` به‌عنوان Blueprint استفاده کنید).
3. متغیرهای محیطی زیر را در بخش Environment تنظیم کنید:
   - `SITE_URL` (آدرس نهایی دامنه شما)
   - `SECRET_KEY` (یک رشته تصادفی طولانی)
   - `ADMIN_EMAIL` و `ADMIN_PASSWORD`
   - `DATABASE_URL` (پیشنهاد: یک Persistent Disk به مسیر `/app/data` وصل کنید و از `sqlite:////app/data/sarmayeyar.db` استفاده کنید، یا یک دیتابیس PostgreSQL در Render بسازید)
4. Deploy کنید — فایل `Dockerfile` به‌صورت خودکار Build و اجرا می‌شود.

## ساختار پروژه
```
app/
  main.py            نقطه ورود FastAPI
  config.py          تنظیمات و متغیرهای محیطی
  models.py           مدل‌های دیتابیس
  routers/
    pages.py          صفحات عمومی سایت
    auth_router.py     ورود / ثبت‌نام
    admin.py           پنل مدیریت کامل
    api.py             API عمومی (برای مشترکین حرفه‌ای)
  services/
    market_data.py      دریافت داده بازار (yfinance + داده نمایشی جایگزین)
    technical_analysis.py  محاسبه RSI، MACD، باند بولینگر و...
    news_service.py     دریافت اخبار و تحلیل احساسات ساده
    scoring_engine.py   موتور امتیازدهی نهایی (قلب سیستم)
    payment.py          لایه پرداخت/اشتراک (آماده اتصال به زرین‌پال)
  templates/           قالب‌های Jinja2 (فارسی، راست‌به‌چپ)
  static/              CSS و JS
```

## نکات مهم درباره داده‌ها
- منبع داده پیش‌فرض `yfinance` است که برای رمزارزها (`BTC-USD`)، سهام جهانی (`AAPL`) و طلا (`GC=F`) کار می‌کند.
- برای نمادهایی که داده واقعی در دسترس نباشد، سیستم به‌صورت خودکار **داده نمایشی (Demo)** تولید می‌کند تا رابط کاربری همیشه قابل نمایش باشد (این حالت با یک برچسب زرد به کاربر اطلاع داده می‌شود).
- برای اتصال بورس ایران (مثل TSETMC) یا صرافی‌های داخلی، کافی است یک آداپتور جدید به `market_data.py` اضافه کنید.
- بخش اخبار به‌صورت پیش‌فرض از تحلیل احساسات ساده (Lexicon-based) استفاده می‌کند. اگر کلید API یک مدل زبانی را در `AI_API_KEY` قرار دهید، می‌توانید `news_service.py` را برای تحلیل عمیق‌تر توسعه دهید.
